# Üçlü Strateji

## Proje Ne Yapıyor?

Üçlü Strateji, iki oyuncunun 3x3 oyun tahtası üzerinde karşılıklı oynadığı basit bir strateji oyunudur.

Her oyuncunun yalnızca üç taşı vardır. Oyuncular önce taşlarını oyun tahtasına yerleştirir. Üç taş da yerleştirildikten sonra yeni taş eklemek yerine mevcut taşlardan biri boş bir kareye taşınır.

Amaç yatay, dikey veya çapraz şekilde üç taşı aynı hizaya getirmektir.

## Proje Neden Faydalı?

Bu proje, nesne tabanlı programlama mantığını uygulamalı olarak göstermek amacıyla geliştirilmiştir.

Projede oyuncular, oyun tahtası ve oyun akışı farklı sınıflar kullanılarak yönetilmektedir.

Bu sayede aşağıdaki Python yapıları kullanılmaktadır:

- Sınıflar
- Nesneler
- Metotlar
- Koşul ifadeleri
- Döngüler
- Listeler
- Kullanıcıdan veri alma
- Oyun durumu kontrolü
- Tkinter ile grafik arayüz

## Oyun Kuralları

- Oyun 3x3 tahta üzerinde oynanır.
- İki oyuncu vardır.
- Her oyuncunun üç taşı bulunur.
- Oyuncular sırayla taşlarını boş karelere yerleştirir.
- Üç taş yerleştirildikten sonra oyuncular mevcut taşlarını hareket ettirir.
- Yatay, dikey veya çapraz üçlü oluşturan oyuncu kazanır.
- Dolu karelere taş yerleştirilemez.

## Proje Nasıl Çalıştırılır?

Projeyi çalıştırmak için bilgisayarınızda Python kurulu olmalıdır.

1. Projeyi bilgisayarınıza indirin.
2. `uclu_strateji.py` dosyasını açın.
3. Dosyayı Python ile çalıştırın.
4. Oyuncu isimlerini girin.
5. Oyuna başlayın.

Komut satırından çalıştırmak için:

```bash
python uclu_strateji.py
```
